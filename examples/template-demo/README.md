# template-demo — the `template` + `params` interpreter, worked example

This folder is a self-contained demonstration of the new template authoring path
described in `docs/MINI_SERIES_TEMPLATE_PLAN.md` §4 (the `PROPOSED` `template` + `params`
fields). The rest of the studio's 26 projects still use `tools/director.py`'s Size-branched
shots; this shows the alternative, data-driven path.

## What to look at

- `story/shots.json` — the input. Six shots, each carrying a `template` name and a `params`
  object. No hand-written draw code.
- `scenes/shots/*.tpl.js` — the OUTPUT, generated by:

  ```
  python tools/template_interpreter.py --project examples/template-demo --check
  ```

  These are the exact same proven draw body that `tools/director.py` emits
  (`projects/cine_release/scenes/shots/01_s001-wide.js`), but driven by `template` + `params`
  instead of a hand-authored `SIZE` switch.

## The 12 archetypes

`tools/archetypes.py` is the registry. The generator-supported ones
(`establish-push`, `medium-two-shot`, `over-shoulder`, `giant-face`, `insert-object`,
`pull-out-bookend`, `freeze-frame`, `title-card`, `end-card`, `transition-whip`) are emitted by
the interpreter. `blueprint-diagram` and `lowpoly-3d` are skipped with a warning — they are
hand-written hero shots (the plan's "3–5 hero shots stay hand-written").

## Notes

- `scenes/cast.js`, `scenes/blocking.js`, `scenes/sets/*.js` are copied fixtures from
  `projects/cine_release` so this demo actually renders. A real season swaps `cast.js` for its
  own characters (signature colours are fixed there) and supplies its own sets.
- The interpreter is ADDITIVE: it writes new `*.tpl.js` files and never edits `engine/`, the
  existing shots, `audio/`, or `render.mjs`. It does not render anything.
- `engine/player.js:74` already spreads `shot.params` into `info`, so the only thing the
  template path adds is the registry + this codegen step.
