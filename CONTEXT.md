# CONTEXT — aitrends-2d-studio

Domain language and architecture context for the local story-to-video pipeline.
Read this before editing tools or proposing refactors.

## What this is

A deterministic, local pipeline that turns a written story into a short vertical
animated video (stick-figure characters, canvas 2D, ffmpeg). Everything runs on
the owner's machine. No AI video generator, no cloud render.

## Core concepts

- **Project** — a directory under `projects/<slug>/` with `config.json`, `story/`,
  `scenes/`, `build/`, `out/`. Created by `tools/new_project.py`.
- **Shot** — one timed segment of a film: `id, start, end, line, scene, set,
  template, params, bars, in, sfx, amb, captions, grade, cut_intent, notes,
  acting`. Defined in `story/shots.json`.
- **Beat** — a word-anchored gesture/timing decision derived from `timeline/words.json`
  by `tools/beats.py`. Shots are built from beats.
- **Set** — a backdrop module in `scenes/sets/*.js` (e.g. `room`, `kitchen`).
  Anchored to `GY` and `CX`.
- **Archetype** — one of 12 named shot templates (`establish-push`,
  `medium-two-shot`, …) defined in `tools/archetypes.py` and emitted by
  `tools/template_interpreter.py`.
- **Cast / blocking** — character definitions (`cast.js`) and per-shot figure
  placement (`blocking.js`), generated by `tools/director.py`.
- **Style lock** — byte-for-byte reference frames stored in `story/style-lock.json`,
  verified by `tools/style_lock.py`. Protects signature colours and look.
- **Approval** — human acceptance bound to `video_sha256`, recorded only by
  `tools/record_approval.py`. Machine checks are not acceptance.

## Pipeline (one film)

voice (TTS) → transcribe (words.json) → beats → direct (director.py: cast,
  blocking, sets, shots) → render (render.mjs) → mix (audio/mix.py) → master
  (audio master) → QC gates (render_gate, scene_coverage, seam_gate, motion_audit,
  review_frames, style_lock, approval_gate) → render_report → human approval.

## Protected paths

See `docs/adr/0001-protected-paths-and-approval-invariant.md`. Do not touch
`engine/`, `audio/sfx.py`, `audio/mix.py`, `render.mjs` without following the
unprotect process.

## Key invariants

1. Approval is bound to delivered bytes; only `record_approval.py` writes it.
2. `generate.py` cannot forge approval (no `--approved-by`).
3. Protected paths change only via a deliberate recorded decision.
4. Machine green ≠ acceptance (human must watch and record words).

## Architecture seams (where refactors land)

- Shot draw body: shared between `tools/director.py` (SHOT_JS) and
  `tools/template_interpreter.py` (BODY_STAGE) — diverged by design
  (parameter slots in interpreter). See ADR appendix.
- Project paths: recomputed in ~14 tools; candidate for a `Project` value object.
- QC gates: 8 tools orchestrated by `generate.py`; candidate for a `Gate` protocol.
- Acceptance: read-side (`check`, `snapshot`) vs write-side (`record`) must stay
  split.
